# 09. ARQUITETURA E TECNOLOGIAS

### &#x20;Visão Geral da Arquitetura

A solução adota uma arquitetura em camadas bem definidas, promovendo a separação de responsabilidades entre a interface com o usuário, as regras de negócio/APIs, o armazenamento persistente e o motor de Inteligência Artificial.

### Componentes da Arquitetura

| **Camada / Componente**      | **Tecnologias / Papel** | **Descrição e Responsabilidades**                                                                                                                                   |
| ---------------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Frontend                     | Interface / Chat        | Interface do usuário responsável por capturar as interações via chat, exibir dashboards, componentes visuais e receber dados do usuário.                            |
| Backend / API                | Python / API            | Camada central de negócios responsável pelo roteamento das requisições, orquestração de regras financeiras, tratamento e envio de dados para a IA e banco de dados. |
| Banco de Dados               | SQL                     | Armazenamento relacional para a persistência segura de perfis de usuários, histórico de movimentações, categorias e registros de métricas financeiras.              |
| Inteligência Artificial      | IA (Análise)            | Motor responsável pelo processamento de linguagem natural (PLN), categorização automática de transações, geração de insights e análises preditivas.                 |
| Ambiente de Ciência de Dados | Jupyter Notebook        | Utilizado para exploração de dados, prototipagem de modelos de IA, treinamento/validação de algoritmos de análise e geração de relatórios experimentais.            |

### &#x20;Fluxo de Comunicação e Dados

\{% hint style="info" %\} Como os componentes se relacionam na prática:

1. Entrada do Usuário: O usuário envia uma mensagem ou comando na interface Frontend.
2. Processamento Central: A API Python recebe a requisição, aplica as validações necessárias e aciona o motor de IA ou consulta o banco SQL.
3. Inteligência e Persistência: A IA interpreta/categoriza as informações, enquanto o banco SQL salva ou recupera o histórico transacional.
4. Análise de Dados: Os dados agregados são explorados via Jupyter Notebook para refinamento contínuo das análises e algoritmos de recomendação. \{% endhint %\}
